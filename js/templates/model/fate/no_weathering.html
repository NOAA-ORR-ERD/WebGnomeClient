More Information Needed to Display Fate View

The following requirements must be met before the model can produce oil fate results. NOTE: if all the items are present, then there may be a mismatch in the time span of the data and/or spill relative to the model run time.

  • One or more spills must be added to the model Set Spill
  • To display oil weathering results, an oil type needs to be added to the spill Set Oil
  • To compute oil weathering, water conditions need to be specified Set Water Properties
  • To compute oil weathering, wind must be added to the model Set Wind Properties
